🛒 React Shop – Version 5

A modern and professional React e-commerce project built to demonstrate real-world frontend skills using clean architecture and best practices.

This project is suitable as a portfolio project for freelancers and frontend developers who want to show their ability to build scalable React applications.

✨ Features

Product listing

Product detail page

Add to cart functionality

Cart page

Global state management with Context API

Client-side routing with React Router

Clean folder structure

Reusable components

Responsive UI

Modern ES6+ JavaScript

Built with Vite for fast development

🧱 Tech Stack

React

React Router

Context API

JavaScript (ES6+)

Vite

Bootstrap

CSS
